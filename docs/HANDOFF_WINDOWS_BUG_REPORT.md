### 1・2. 最近読んだスレのタイトル

- **原因:** 開いた時点のタイトルで記録していた。リンクや過去ログから開くとタイトルが無く、
  URL 末尾のスレ番号が残っていた。
- **修正:** スレを取得してタイトルが分かったら `refreshRecentThreadTitle()` で
  「最近読んだ」「最近書き込んだ」の表示名を直す。並び順と日時は変えない。
  呼び出し元は `fetchResponsesFromCurrent` と全タブ更新の 2 か所。
- **手順:**
  1. スレに貼られた別スレのリンク (`https://xxx.5ch.io/test/read.cgi/...`) を踏んで開く。
  2. 過去ログのスレを開く。
  3. 「最近読んだスレ」を開き、どちらもスレ番号ではなくスレタイで出ていることを確かめる。
- **ついでに見ること:**
  - 修正前に記録されたスレ番号の行も、そのスレを開き直せばスレタイに変わるか。
  - 開き直したときに一覧の並び順が変わらないか。

### 3. 狭い幅での横スクロールバー

- **原因:** アプリ全体の枠 `.shell` に列幅の指定がなく、暗黙の `auto` 列が中身の最大幅まで
  広がっていた。縦積み (`.narrow-layout`) では `.layout` が flex になり、列幅の縛りが消える。
- **修正:** `.shell` に `grid-template-columns: minmax(0, 1fr)` を足した。
- **手順:**
  1. 横に広いウィンドウでスレを 10 本ほど開く。
  2. 板一覧が上に移るまでウィンドウを狭める。
  3. アプリ全体の横スクロールバーが出ないことを確かめる。タブバーは内側で
     スクロールし、◀ ▶ ボタンも効くこと。
- **ついでに見ること:** UI サイズ (WebView のズーム) を上げた状態でも同じか。

### 4. ポップアップ内の「クリックで表示」

- **原因:** 枠を画像に差し替える処理が本文ペインのクリック処理にしか無かった。
  ポップアップは本文ペインの外に描かれるので、そのクリックを拾えていなかった。
- **修正:** 差し替えを `revealGatedThumb()` に切り出し、本文とポップアップ
  (`handlePopupImageClick`) の両方から呼ぶ。
- **手順:**
  1. 設定の [画像・リンク] → [サムネイルを自動で読み込む] を OFF にする。
  2. 画像が貼られたレスへのアンカー (`>>N`) にホバーして、ポップアップを出す。
  3. 「クリックで表示」を押し、ポップアップ内に画像が出ることを確かめる。
- **ついでに見ること:**
  - 押したときにポップアップが閉じないか。
  - YouTube のサムネと、サイズ制限で隠れた画像も同じように出るか。
  - 出た画像を押すとライトボックスが開くか。

### 5. 「スレ一覧を更新」の対象

- **原因:** 更新先に `threadUrl` (開いているスレの URL) を使っていた。タブを全部閉じたあとも、
  最後に開いていたスレの URL が残る。
- **修正:** 引数なしの `fetchThreadListFromCurrent()` と自動更新の `refreshThreadListSilently()` は、
  `fetchedThreadsBoardUrlRef` (今表示している一覧を取った URL) を優先する。
  これでツールバーのボタン、Ctrl+Shift+R、メニューの「スレ取得」、
  ショートカット割り当ての reloadThreadList がすべて表示中の板を更新する。
- **手順:**
  1. 板 A のスレ一覧を表示する。
  2. お気に入りから板 B のスレを開く。
  3. ツールバーの「スレ一覧を更新」を押し、板 A の一覧が更新されることを確かめる。
  4. タブを全部閉じて、同じく板 A が更新されることを確かめる。
  5. 自動更新を ON にして同じ状態で待ち、一覧が板 B に変わらないことを確かめる。

### 6. 三段表示でスレッド窓を隠したときの空白

- **原因:** 縦積み (`.narrow-layout`) ではスレ一覧の高さに `max-height: 40vh` の上限がある。
  スレッド窓が押し出されないためのものだが、スレッド窓を隠しても上限が残っていた。
  分割線をドラッグして決めた高さ (`narrowThreadPanePx`、インラインの `height` / `max-height`)
  も同じく残っていた。
- **修正:**
  - スレッド窓 (`responsePaneHidden`) を隠している間は、`.right-pane` に
    `responses-hidden` クラスを付ける。
  - `styles.css` で、そのクラスがあるときはスレ一覧を `flex: 1 1 auto; max-height: none` にする。
  - 同じ間は `narrowPaneStyle(narrowThreadPanePx)` を当てない。
- **手順:**
  1. 板一覧が上に移って三段表示になるまでウィンドウを狭める。
  2. ツールバーの [スレッド窓を隠す] を押し、スレ一覧が下端まで広がることを確かめる。
  3. もう一度押して表示し直し、スレ一覧が元の高さに戻ることを確かめる。
  4. 分割線をドラッグしてスレ一覧の高さを変えてから、2・3 を繰り返す。
- **ついでに見ること:**
  - 横並びの通常表示と川型表示で、隠す・出すの動きが変わっていないか。
  - 板一覧も隠した状態 (スレ一覧だけ) でも、下に空白が出ないか。
