# Mac 引継ぎ: モバイル版の通知タブ・スレ立て通知・同じ本文の連投 NG（2026-11-14）

Windows で次の 3 つを実装した。jest と eslint とバンドルは通ったが、**画面では一度も動かしていない。**
iOS シミュレーターで動きを確かめ、見つけた不具合を直してほしい。

1. **通知タブ（履歴）**: 出した通知を一覧で見られるボトムタブ
2. **スレ立て通知**: 登録した板に、ワードを含むスレが立ったら通知する
3. **同じ本文の連投 NG**: ID を変えて同じ長文を貼る荒らしを隠す（NG 設定）

## シミュレーターの制約（先に読む）

- **バックグラウンドの巡回（BGTaskScheduler）はシミュレーターでは動かない。**
  巡回は設定 → 通知 の **「今すぐ確認」** で動かす。この経路は前面でも通知を出す（`data.foreground`）。
  この経路でも履歴への記録・通知のタップ処理・スレ立ての判定は同じコードを通る。
- idb は Xcode 27 に対応しておらず、**タップを送れない。** 画面の操作はユーザーにお願いし、
  確認には `xcrun simctl io booted screenshot <file>.png` を使う（`docs/MOBILE_FEASIBILITY_STUDY.md` §M2 の記録と同じ運用）。
- 通知の許可ダイアログは初回だけ出る。やり直すときは `xcrun simctl privacy booted reset notifications net.votepurchase.ember`。

## Mac での確認結果（2026-11-14）

iOS シミュレーター（iPhone 18 Pro / iOS 27.2）で、Maestro で操作して確かめた。Mac でも `npx jest` は通った
（watchman が壊れているので `--no-watchman`）。

### 直した不具合

1. **`ember://thread` で開いたスレが、通知の巡回とホームの新着確認から外れる**（A4 で発覚。今回の変更より前からある）。
   リンクには板の URL が無く、控え（watchList）に `boardUrl` の無い行ができていた。`selectNotifyTargets` と
   ホームの `checkAll` は `boardUrl` の無い行を黙って飛ばす。
   - `Thread.js`: `boardUrl` が来ないときはスレの URL から割り出す
   - `watch.slice.js` の `touchThread`: 既にある行に `boardUrl` が欠けていれば埋める（開き直せば直る）
2. **スレ立て通知が、運営の告知スレで登録直後に鳴る**（B4 で発覚）。「★ UPLIFT プレミアム・サービスのお知らせ」は
   `9240230830`（西暦 2262 年）という未来の番号で板の先頭に置かれるので、「登録より後に立った」と判定されていた。
   - `notify.js`: 番号が今より `ALERT_FUTURE_SLACK_SEC`（1 日）を超えて先のスレは対象外。テストを足した

### 足した機能

- **通知タブの長押しメニュー**（ユーザーの要望）: 「お気に入りに追加 / 外す」「監視に追加 / やめる」（ホームで監視を
  出しているときだけ）「一覧から削除」。ホームの長押しと同じボトムシート。`notifyHistory.js` に `removeItems` /
  `removeHistoryItems` を足した

### C4 の結果（直していない。判断は Windows 側）

AA の 3 板（AAサロン・AA長編・モナー）の勢いのある 24 スレで `findDupBodyNumbers` を回すと、
**繰り返しの判定に 199 件、同じ本文の判定に 454 件**が当たった。中身は AA 長編のコマ（`:::::` や `.:.:.:` の背景、
雨や星空の模様）と、同じ AA の貼り直し。既定が「無効」なのは妥当だが、「非表示」を選んだ人が AA の板を開くと
かなり消える。AA の板では効かせない、繰り返しの判定を外す、などを検討してほしい。
