# Mac 引継ぎ: モバイル版の通知タブ・スレ立て通知・同じ本文の連投 NG（2026-11-14）

Windows で次の 3 つを実装した。jest と eslint とバンドルは通ったが、**画面では一度も動かしていない。**
iOS シミュレーターで動きを確かめ、見つけた不具合を直してほしい。

1. **通知タブ（履歴）**: 出した通知を一覧で見られるボトムタブ
2. **スレ立て通知**: 登録した板に、ワードを含むスレが立ったら通知する
3. **同じ本文の連投 NG**: ID を変えて同じ長文を貼る荒らしを隠す（NG 設定）

## 前提

- ブランチ: `mobile-notify-history`（push 済み）/ 実装の commit: `c5e67e9`。main からの差分はモバイルとドキュメントだけ（デスクトップの同じ本文の連投 NG は Windows の作業ツリーに残してある）
- Windows で通ったもの:
  - `npx jest`（50 スイート / 773 件）
  - `npx eslint src __tests__`（エラー 0）
  - `npx expo export --platform android`（バンドルが通る）
- 確認が済んで問題がなければ main に入れる。モバイルのリリース（EAS）は別に判断する

```bash
git fetch && git switch <ブランチ>
cd apps/mobile
yarn install
npx jest                 # まず Mac でも通ることを確かめる
npx expo run:ios         # シミュレーターに開発ビルドを入れて起動
```

## シミュレーターの制約（先に読む）

- **バックグラウンドの巡回（BGTaskScheduler）はシミュレーターでは動かない。**
  巡回は設定 → 通知 の **「今すぐ確認」** で動かす。この経路は前面でも通知を出す（`data.foreground`）。
  この経路でも履歴への記録・通知のタップ処理・スレ立ての判定は同じコードを通る。
- idb は Xcode 27 に対応しておらず、**タップを送れない。** 画面の操作はユーザーにお願いし、
  確認には `xcrun simctl io booted screenshot <file>.png` を使う（`docs/MOBILE_FEASIBILITY_STUDY.md` §M2 の記録と同じ運用）。
- 通知の許可ダイアログは初回だけ出る。やり直すときは `xcrun simctl privacy booted reset notifications net.votepurchase.ember`。

## 確かめてほしいこと

### A. 通知タブ

| # | 操作 | 期待 |
|---|---|---|
| A1 | 通知がオフの状態で起動 | タブは「ホーム・板・検索・設定」の 4 つ |
| A2 | 設定 → 通知 →「通知する」をオン | 「検索」と「設定」の間に「通知」タブ（ベルのアイコン）が出る |
| A3 | 通知タブを開く（履歴なし） | 「まだ通知はありません」。「すべて既読」は灰色で押せない |
| A4 | ホームの「監視」に流れの速いスレを入れ、少し待ってから「今すぐ確認」 | 通知が出る。タブに未読数のバッジが付く。一覧の先頭に「監視の新着」が未読（左の印・太字）で並ぶ |
| A5 | 一覧の行をタップ | そのスレが開く。戻るとその行は既読になり、バッジが 1 減る |
| A6 | 未読が複数ある状態で「すべて既読」 | すべて既読になり、バッジが消える |
| A7 | 通知センターに残った通知をタップ（アプリは前面か背面） | そのスレが開き、履歴のその行が既読になる |
| A8 | アプリを終了（上にスワイプ）してから、通知センターの通知をタップ | 起動後にそのスレが開く（`getLastNotificationResponseAsync` の経路）。もう一度起動し直しても、同じスレが勝手に開かない |
| A9 | 通知をオフにする | 通知タブが消える。オンに戻すと前の履歴がそのまま残っている |
| A10 | 通知タブを開いたまま、ホームのベルで通知をオフ | 落ちずに別のタブへ移る |
| A11 | ダークモード | 未読の印、バッジ、文字の色が読める |

### B. スレ立て通知

**流れの速い板で、広く当たるワードを使う**と待ち時間が短い。たとえばニュー速系の板で `】` や `の`。
**登録より後に立ったスレだけ**が対象なので、登録してから新しいスレが立つまで待ってから「今すぐ確認」を押す。

| # | 操作 | 期待 |
|---|---|---|
| B1 | 板のスレ一覧を開く（通知オン） | ヘッダーにベル（斜線入り）が出る。通知オフのときは出ない |
| B2 | ベルを押す | 「スレ立て通知の追加」が開き、板が選ばれている。ワードを 1 行に 1 つ入れて「登録」 |
| B3 | 戻ったスレ一覧のヘッダー | ベルが斜線なしに変わる。押すと「スレ立て通知の編集」が開く |
| B4 | 登録の直後に「今すぐ確認」 | **今ある（登録前の）スレでは鳴らない** |
| B5 | 新しいスレが立ってから「今すぐ確認」 | 「新スレ: 板名」の通知が出る。通知タブに「スレ立て」の行が並ぶ。タップするとそのスレが開く |
| B6 | もう一度「今すぐ確認」 | 同じスレで 2 度は鳴らない |
| B7 | 設定 → 通知 の「スレ立て通知」 | 条件が板名とワードで並ぶ。タップで編集、「この条件を消す」で消える |
| B8 | 「条件を追加」から板を選ぶ | お気に入りの板と最近開いた板が並ぶ。5 件登録すると「条件は 5 件までです」で押せない |
| B9 | 種類の「スレ立て」をオフ → 新しいスレが立つのを待つ → オンに戻して「今すぐ確認」 | オフの間に立ったスレでは鳴らない |
| B10 | スレ一覧 NG ワードに当たるスレ | 通知しない |
| B11 | 1 板で 4 件以上が一度に当たる（広いワードで少し長く待つ） | 「N 件: … ほか」の 1 件にまとまる。タップで通知タブが開く。履歴には 1 スレずつ並ぶ |
| B12 | ワードの入力欄 | 複数行が打てる。キーボードで「登録」が隠れない（隠れるならスクロールで届くか） |

### C. 同じ本文の連投 NG

| # | 操作 | 期待 |
|---|---|---|
| C1 | 設定 → NG 管理 の「同じ本文の連投」 | 既定は「無効」。「非表示」「あぼーん」を選べる |
| C2 | コピペ荒らしのいるスレを開き「非表示」にする | 同じ長文（60 文字以上が 3 回以上）と、同じ並びの繰り返しばかりの長文が消える。`>>1` と短い同文（「うおおお」など）は残る |
| C3 | 「あぼーん」にする | 消えずに「あぼーん」の行になる。どの NG に当たったかの表示は「同じ本文の連投」 |
| C4 | 大きな AA が並ぶスレで「非表示」 | AA が誤って消えないか見る（**繰り返しの判定が AA に当たる心配があり、既定を無効にした理由**）。当たるなら報告してほしい |

## 気になっている点（直すかは結果次第）

- スレ一覧のベルは、未登録を斜線入り（`bellOff`）にした。「通知が切れている」と読めるなら別のアイコンにする
- 巡回の記録の「N 本を確認」に、スレ立て通知の条件の数も入る
- 通知タブのヘッダーは他のタブの最上位と同じくナビゲーションのヘッダーを持たず、画面内の帯（「通知（未読 N）」と「すべて既読」）だけ
